# 프로젝트 소개

‘햄매니저’는 지원서를 보관하고, 임베딩 처리 기반 유사 자소서 검색을 지원하는 1인 개발 웹 애플리케이션입니다.

<br>

## 기술 스택

#### Backend

Java17, Spring Boot 3.3.4, Spring Data JPA, RabbitMQ

#### Database

MySQL, Redis, Pinecone vectorDB

#### Infra

AWS EC2, RDS, S3, ECR, CI/CD(Github action), Docker

#### External API

Upstage embedding API
